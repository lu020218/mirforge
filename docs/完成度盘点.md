> 2026-09-15 整理。基准：一套可开服运营的完整传奇 2 前后端。

## 二、明确缺失（按传奇玩家的必需度排序）

### 第一梯队 —— 没有就不算传奇

- **交易 / 组队**：协议消息已定义（TradeRequest / CreateParty 等），服务端处理逻辑为零，纯占位
- **PK 体系**：红名 / 灰名 / 善恶值 / 安全区 / 守卫攻击红名，完全没有
- **仓库**（NPC 寄存）
- **装备耐久与修理**（普通修 / 特修）
- **武器升级**（黑铁矿 + 首饰投入，随机成败）
- **声音**：客户端没有任何音效 / 音乐代码 —— 当前体感差距最大的一项
- **属性深度**：目前只有攻 / 防 / 魔 / 道四项，准确 / 敏捷 / 魔法躲避 / 中毒躲避 / 幸运 / 诅咒都没有
- **极品装备**：掉落时随机附加属性与概率配置（规划.txt 第 1 条已列）

### 第二梯队 —— 运营必备

- 行会系统 + 沙巴克攻城（传奇的灵魂玩法，也是最大单体工程）
- 随机传送卷 / 回城卷；道士毒药、护身符（消耗品弹药）；食物药剂 buff
- 掉落归属保护（谁打的归谁一段时间）
- GM 游戏内指令（踢人 / 封禁 / 发物 / 传送）、封号禁言、操作日志审计
- 反外挂基线：服务端速度 / 频率校验、封包合法性
- 自动寻路 + M 键大地图（规划.txt 第 2 条已列）

### 第三梯队 —— 锦上添花

- 坐骑 / 翅膀（**素材已购入在 resources/Items/，尚未接入**）、时装
- 师徒 / 婚姻、排行榜、邮件、节日活动系统

## 三、内容量差距（最容易被低估）

当前配置库：**7 件物品、9 个技能、2 张地图、1 个 NPC、3 个任务**。
经典传奇量级：300+ 物品、每职业 12+ 技能、40+ 地图、几十个 NPC、成体系的任务链。

- 好消息：管理台 + hub 这套配置管线已打通，填内容**不需要写代码**
- 坏消息：素材转码、逐怪逐图的调试（帧对位 / 基址 / 锚点）随内容量线性放大

## 四、技术债

1. 技能 9 型分类只落地 7 型：**瞬移(Blink) / 击退(Knockback) / 增益(Buff) / 减益(Debuff) / 地面持续(GroundAoe) / 强化(Empower)** 批次②-⑤未做
2. 游戏循环单线程单区：百人以上同屏需要分区并行化验证与压测
3. 技能动作匹配、技能特效配置仍是半成品（规划.txt 第 3、4 条）
4. 玩家实体广播不带 HP（目标栏锁玩家只显示名字），PvP 前需补
5. Crystal 原版资源兜底路线已废除，个别库若 packs 缺失会直接空帧

## 五、建议优先级路线

```
声音 → 交易 + 仓库 → PK/安全区 → 耐久修理 + 极品属性 → 组队
  → 内容填充到一条完整地图链 (比奇省 → 沃玛森林 → 沃玛寺庙)
  → 行会 + 沙巴克攻城
```

- 前五项每项 1-3 天量级（照现有配置化 / 迁移 / 面板模式做）
- 行会 + 攻城是唯一需要按周计的硬骨头
- 内容填充可与功能开发并行（不占代码位）
