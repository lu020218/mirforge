# MirForge 服务端管理台 使用说明

面向服主/策划的操作手册。讲**怎么用**；数据表结构与设计取舍见
[ADMIN_CONFIG.md](ADMIN_CONFIG.md)，NPC 系统的分期设计见 [NPC_DESIGN.md](NPC_DESIGN.md)。

---

## 一、打开管理台

服务端启动后自带管理台，无需另开进程。启动日志里会打印地址：

```
INFO mirforge_server::admin: 管理台: http://127.0.0.1:4001
```

浏览器打开该地址即可。开发环境用一键脚本启动：

```bash
tools\dev-server.ps1
```

### 相关环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `MIRFORGE_ADMIN` | `127.0.0.1:4001` | 管理台监听地址；设为 `off` 完全关闭 |
| `MIRFORGE_ADMIN_TOKEN` | 无 | 访问令牌，见下 |
| `MIRFORGE_DB` | `mirforge.db` | SQLite 路径，**配置与角色存档同库** |
| `MIRFORGE_RES` | 无（必需） | 地图资源根目录，含 `Map/`（内放 `.map` 文件） |
| `MIRFORGE_PACKS` | `packs`（工作目录相对） | 图库包根目录（`.mfl`，见 packs/README.md）；dev 脚本会设为仓库根 `packs/` 的绝对路径 |

### 安全须知

默认只绑定 `127.0.0.1`，即**仅本机可访问**，不需要令牌。

一旦把 `MIRFORGE_ADMIN` 改成对外地址（如 `0.0.0.0:4001`），**必须**同时设置
`MIRFORGE_ADMIN_TOKEN`，否则服务端会拒绝启用管理台并打印错误。此时每个请求都要带
`x-admin-token` 头——在「服务器设置 → 管理令牌」里填一次，浏览器会存进
localStorage（仅本浏览器有效，留空即清除）。

> 管理台没有账号体系，**令牌就是唯一凭据**。请勿把它暴露在公网而不加反向代理限制。

所有写操作都会追加一行 JSON 到服务端工作目录下的 `admin-audit.log`
（当前记录 `broadcast` / `put_config` / `add_zone` / `put_zone` / `delete_zone`）。

## 二、通用规则（每页都适用）

**保存即生效。** 每页各自有「保存 X」按钮，保存后立即写库并热重载，在线玩家无需重连。
数据库是唯一真源，`server/data/*.json` 只在**首次建库**时作为种子导入一次，之后不再读写。

**服务端是唯一校验点。** 保存前先跑校验，任何一条不过就整单拒绝、原样回显错误，
不会写入一半。常见错误与含义见「十一、校验错误速查」。

**「重新载入」= 放弃本页未保存的改动**，从数据库重新拉一份。

**页面之间互不干扰。** 在物品页改了没保存，切到技能页再切回来，改动仍在。
只有 NPC 页与 BOSS 页是**首次进入时载入一次**（因为它们有跨页取点流程），
之后要放弃编辑请显式点「重新载入」。

**表格行的「删」只删这一行**，同样要点「保存」才落库。

## 三、Dashboard

只读的运行状态总览，每 2 秒自动刷新。

- 五张卡片：运行时长 / 在线玩家 / 怪物存活·总数 / 地面物品 / 区域数
- 在线角色表：角色名、等级、所在区域、坐标、HP、连接状态
- 每行右侧「踢下线」按钮可断开该角色的连接（角色数据不受影响，可重新登录）

## 四、物品设置

一行一个物品模板。列：

| 列 | 说明 |
|---|---|
| **template** | 物品 id，全局唯一。其它地方（商店、掉落、任务奖励）都引用它 |
| **名称** | 显示名 |
| **槽位** | 只能是 `weapon` / `armor` / `helmet` / `necklace` / `ring`，填别的会被拒 |
| **攻击 / 魔法 / 道术 / 防御 / HP** | 穿戴后的属性加成。攻击=战士系（普攻与战士技能），魔法=法师技能，道术=道士技能 |
| **价格** | 商店基准价。商店未单独定价时按它卖；**玩家卖回 NPC 的回收价 = 基准价 × 50%** |
| **图标帧** | `Data/Items.Lib` 的帧号。点右侧缩略图可从图库分页挑选 |
| **外观** | 穿在身上的外观库号：weapon → `CWeapon`，armor → `CArmour` |

价格填 0 表示不值钱，卖给 NPC 得 0 金。

## 资源查看

侧栏「运维 → 资源查看」。浏览 `packs/` 下全部 .mfl 图库:

- 左侧列表按目录分组 (armor/weapon/monster/npc/map/magic/…), 显示文件大小;
- 点击图库加载帧网格, 每格标注帧号; 「跳过空帧」隐藏素材包里的占位帧;
- 「跳到帧」输入帧号回车直达; 上一页/下一页每页 60 帧;
- 点任意帧看原尺寸大图与元信息 (尺寸/锚点偏移)。

用途: 配置物品图标帧、怪物/NPC 形象号、技能特效帧段时, 先在这里翻到
目标帧号再回配置页填写。

## 五、技能设置

按职业分组，一行一个技能。列：

| 列 | 说明 |
|---|---|
| **职业** | 战士 / 法师 / 道士 |
| **id** | 技能 id，全局唯一 |
| **名称 / MP / 冷却ms / 等级 / 射程** | 字面意思；「等级」是可学会的最低角色等级 |
| **自身** | 勾上表示以自己为中心施放，不需要选目标 |
| **类型** | 单体伤害 / 范围伤害 / 治疗 |
| **参数1 / 参数2** | 随类型联动：单体=伤害倍率；范围=半径 + 倍率；治疗=无参 |
| **满级** | 修炼满级。官方设定 3；调成 4 或 5 可做高级技能玩法（4 级起施放带金色强化特效） |
| **修炼基数** | 从 L 级升到 L+1 级需要施放「基数 × (L+1)」次。基数 30 时 0→3 级共需 30+60+90=180 次 |
| **每级加成** | 每修炼一级的伤害/治疗加成比例。0.3 = 每级 +30%（3 级 ×1.9，5 级 ×2.5） |

技能修炼度随角色存档：每次施放 +1 熟练度，升级时全服务端结算、客户端弹「《技能》修炼至 N 级!」。

改完保存，**在线玩家的技能栏会立即刷新**，不用重登。

## 怪物设置

怪物模板表 — **数值一次定义,各地图的刷新点按模板引用**。列:

| 列 | 说明 |
|---|---|
| **id** | 模板 id,全局唯一。刷新点与任务击杀目标都引用它 |
| **名称** | 显示名 |
| **形象** | packs/monster 的库号,点缩略图从怪物图库可视化挑选 |
| **HP / 伤害 / 经验** | 战斗数值 |
| **被动** | 勾上则不主动仇恨玩家 |
| **掉落** | 格式 `物品模板:概率`,逗号分隔 |

保存后**全部刷新点怪立即按新数值重刷**(在场的会重置);摆放位置在
「地图设置」的区域编辑器里配。旧存档首次启动时会自动从既有刷新点
蒸馏出模板,无需手工搬运。

## 六、NPC 设置

一行一个 NPC。顶部可按地图筛选。列：id / 名称 / 地图 / x / y / 形象 / 类型 / 摘要 / 启用。

- **地图**：下拉只列已接入的区域。没接入的图先去「地图设置」接入
- **形象**：`Data/NPC/{n:02}.Lib` 的库号，点缩略图可从形象库分页挑选
- **类型**：对话 / 商店 / 任务。**只有「商店」才允许配售货清单和「打开商店」选项**
- **摘要**：自动显示「对话 N 页 · 商店 N 件」，一眼看出配没配
- **启用**：取消勾选即从游戏里撤下，不必删除

### 定位（两种取点方式）

1. **行内取点**：点「对话」展开手风琴，里面有「定位」段，直接嵌着地图视口，
   左键点图即写入坐标，可反复微调不跳页
2. **跨页取点**：点行上的「取点」按钮跳到地图页取，取完自动跳回并高亮该行

反向也支持：在「地图设置」的地图视口里点「取点: 新 NPC」，点图后会跳到 NPC 页
并插入一条预填了地图与坐标的新行。

地图视口上，NPC 显示为**紫色**标记，BOSS 为**橙色**，出生点金色、传送门青色、刷新点红色。

### 对话

点「对话」展开。结构是**两层：页 + 选项**。

- 一页 = 一段正文 + 若干选项；玩家点击 NPC 时弹出**页号最小**的那一页
- 一个选项 = 选项文字 + 动作 + 参数

可选动作：

| 动作 | 参数 | 说明 |
|---|---|---|
| 跳到指定页 | 页号 | 对话树的分支与回跳 |
| 接取任务 | 任务 id | 走现有任务系统 |
| 交付任务 | 任务 id | 目标未达成时点了不会生效 |
| 打开商店 | 无 | 仅商店类型可用 |
| 传送 | `地图:x:y` | 落点不可站立时自动吸附到最近可走格 |
| 结束对话 | 无 | 关闭对话框 |

### 商店

类型选「商店」后，手风琴里出现「售货清单」段。每行：物品（下拉，带基准价提示）、
售价、库存。

- **售价填 0** → 用物品的基准价
- **库存 -1** → 无限；填正数则卖一件减一件
- 库存**只在内存里减**，服务端重启或保存 NPC 配置即恢复为配置值（相当于开服补货）

**进店入口有两种**（这是最容易踩的坑）：

- **没配对话页** → 点击 NPC 直接开店（最省事，只上架商品就能用）
- **配了对话页** → 必须在某一页放一个「打开商店」选项，否则玩家进不了店；
  保存时会拦下并提示

## 七、任务设置

一行一个任务。列：id / 名称 / 击杀目标 / 经验 / 金币 / 物品奖励 / 前置任务。

- **前置任务**：下拉自动排除自己；前置未交付时该任务不会出现在可接列表里
- 点「目标/奖励」行内展开，里面是两张表

### 击杀目标

目标是**下拉**而非手填，列出各区刷新点模板与**所有 BOSS**
（BOSS 的模板 id 就是它自己，击杀同样计入任务）。数量单独一列。

全部目标达成后才能交付。目标写错会被保存时拦下——写错原本是静默失败，
任务永远推不动且毫无提示。

### 奖励

经验、金币直接在行里填；物品奖励在展开区里配（物品下拉 + 数量）。

交付时依次发放。**物品奖励会先整单占位检查**：背包件数 + 奖励件数超过上限（50）
就整单不发，提示「背包空位不足」，并**保持任务为进行中**——不消耗任务状态，
玩家清理背包后还能再来交。

单个任务的奖励总件数不能超过背包上限，否则等于永远交不了，保存时会拦。

## 八、地图设置

上半部是已接入区域列表，下半部是行内展开的区域编辑器。

### 接入新地图

工具条左侧下拉列出资源目录里所有**尚未接入**的 `.map` 文件，可输入关键字筛选。
选中后点「接入为新区域」，会以默认边车配置接入并**立即生效**（无需重启），
之后再编辑出生点等。

列表右侧「移除」把该区域撤下（**不会删除地图文件**，随时可再接入）。
三种情况会拒绝移除：它是缺省出生区域、当前有玩家在场、或有别的区域的传送门指向它。

### 区域编辑器

点某行「编辑」，编辑器就在这一行下方展开。顶部一排是基础字段：

- **区域名**：玩家看到的名字，也显示在大地图标题
- **出生点 X/Y**：新角色与复活落点
- **小地图帧**：`Data/mmap.Lib` 的帧号，客户端小地图与大地图都用它。
  点「选择…」可从缩略图网格里挑，**不填则客户端不显示地图**

### 地图视口

编辑器里嵌的是**原图瓦片视口**，不是缩略图：

- **右键拖动**平移，**滚轮缩放**（以光标为锚点），工具条有 `−` `+` `1:1` `适应`
- 左下角显示当前光标的格坐标
- 右下角叠着小地图，点它可快速跳转视口
- 四个「取点」按钮：出生点 / 新传送门 / 新刷新点 / 新 NPC。
  点按钮后左键点图即写入，`Esc` 取消

### 传送门

每行：X / Y / 目标地图 / 落点X / 落点Y。玩家走到 (X,Y) 附近即传送。
落点留空则用目标地图的出生点。

### 怪物刷新点

每行：怪物模板(下拉) / X / Y / 数量 / 半径。

- **模板**：从「怪物设置」页定义的模板里选,形象与数值都跟模板走
- **数量 + 半径**：在 (X,Y) 为中心、半径范围内随机撒 N 只
- 普通怪固定 **30 秒**重生；要长重生 + 击杀公告请用 BOSS 页

保存区域后会**重建该区怪物**（在场的怪会重置）。

## 九、BOSS 设置

与刷新点的区别：刷新点是「一片区域里刷 N 只、30 秒重生」，BOSS 是
「**某个点上唯一的一只、按配置长时间重生、可全服公告**」。

一行一个 BOSS，可按地图筛选。列：

| 列 | 说明 |
|---|---|
| **id / 名称** | id 唯一；名称用于击杀公告，也是任务目标下拉里的显示名 |
| **地图 / x / y** | 定点刷新位置 |
| **形象** | `Data/Monster/{n:03}.Lib`，点缩略图从怪物图库挑选 |
| **HP / 伤害 / 经验** | 战斗数值 |
| **重生** | 秒。默认 1800（30 分钟） |
| **半径** | 游荡半径，**0 = 钉在原地** |
| **公告** | 勾上则击杀后全服播报「勇士 X 击杀了 Y」 |
| **掉落** | 展开区里配，物品 + 概率（0~1，每项独立判定） |
| **启用** | 取消即撤下 |

点「掉落」展开，里面同时有**定位段**（嵌地图视口，可就地取点）和**掉落表**。

保存后立即重刷 BOSS：撤掉旧的、按新配置重新落地。**在场的 BOSS 会被重置为满血回原位**
——配置既然改了就以新配置为准。普通刷新点不受影响。

## 十一、校验错误速查

保存被拒时错误会显示在该页顶部。按出现频率排：

| 错误 | 怎么改 |
|---|---|
| `物品 X 槽位非法` | 槽位只能填 `weapon`/`armor`/`helmet`/`necklace`/`ring` |
| `... id 重复` | 新增行的 id 还是默认值（`new_npc`/`new_boss`/`new_quest`），改成有意义的名字 |
| `NPC X 的地图未接入为区域` | 先去地图设置接入该图 |
| `NPC X 的坐标不可站立` | 点在墙里/水里了，用「取点」重新选 |
| `NPC X 配了售货清单, 但类型不是「商店」` | 把类型改成「商店」，或清空售货清单 |
| `NPC X 是商店且已上架 N 件, 但对话里没有任何「打开商店」选项` | 在某一页加一个「打开商店」选项 |
| `NPC X 第 N 页选项「…」跳转到不存在的页` | 参数填的页号没有对应的对话页 |
| `NPC X 第 N 页选项「…」引用的任务不存在` | 任务 id 拼错，去任务页核对 |
| `NPC X 第 N 页选项「…」传送参数应为 地图:x:y` | 格式必须是三段，如 `2.map:300:300` |
| `任务 X 的击杀目标不存在于任何刷新点或 BOSS` | 目标必须是某个刷新点的模板或某个 BOSS 的 id |
| `任务 X 奖励引用的物品不存在` | 物品 template 拼错 |
| `任务 X 的物品奖励共 N 件, 超过背包上限 50` | 减少奖励件数 |
| `BOSS X 的重生间隔必须大于 0 秒` | 重生秒数不能填 0 |
| `BOSS X 掉落 Y 的概率应在 0~1 之间` | 概率是小数，0.2 表示 20% |

## 十二、典型流程示例

### 加一件装备并让 NPC 卖它

1. **物品设置** → 新增物品，填 template / 名称 / 槽位 / 属性 / 价格 / 图标 → 保存
2. **NPC 设置** → 找到商店 NPC（类型必须是「商店」）→ 点「对话」展开 →
   在「售货清单」里 + 上架物品，选中刚建的物品，售价填 0（用基准价）→ 保存
3. 进游戏点那个 NPC 即可看到新货

### 做一条「打怪交任务」的链

1. **任务设置** → 新增任务，填 id / 名称 / 经验 / 金币 → 点「目标/奖励」→
   目标选怪物模板与数量，奖励里加物品 → 保存
2. **NPC 设置** → 给发布任务的 NPC 加一页对话，放两个选项：
   「接取任务」参数填任务 id、「交付任务」同样参数 → 保存
3. 进游戏找该 NPC 接任务

### 放一个新 BOSS

1. **地图设置** → 确认目标地图已接入
2. **BOSS 设置** → 新增 BOSS，改 id / 名称，选地图，点「掉落」展开，
   在定位段的视口里点一下确定坐标
3. 形象点缩略图从怪物图库挑，填 HP / 伤害 / 经验 / 重生秒数，勾上公告
4. 掉落表里加物品与概率 → 保存
5. 保存后 BOSS 立即刷出，无需重启

## 十三、常见疑问

**改了配置要重启吗？**
不用，全都是热重载。接入新地图也不用——服务端会当场解析地图、构建行走网格并挂上，
在线玩家立刻就能走过去。

**改错了能撤销吗？**
没有撤销功能。未保存前点「重新载入」可放弃改动；已保存的只能手工改回来。
建议改大配置前先备份 `MIRFORGE_DB` 指向的 `.db` 文件。

**`server/data/*.json` 还有用吗？**
只在**首次建库**（数据库为空）时作为种子导入一次。之后改它们不会有任何效果，
一切以数据库为准。要重新种子化，只能删库重建。

**为什么商店库存重启后又满了？**
这是刻意的：库存是内存里的运行期计数，重启或保存 NPC 配置即恢复为配置值，
相当于每次开服补货。要做真正持久的限量，需要改成入库存储。

**BOSS 击杀公告没出现？**
检查该 BOSS 的「公告」是否勾上，以及它是不是真的被玩家击杀的（自然死亡不播报）。

**NPC 明明配了商品，点它却只弹普通对话？**
见「六、NPC 设置 → 商店」的「进店入口」——多半是配了对话页却没放「打开商店」选项。
现在保存时会拦下这种配置，但旧数据可能仍有此问题，重新保存一次即可暴露。
