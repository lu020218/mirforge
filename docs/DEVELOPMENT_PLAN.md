# 开发计划 —— 开源现代化传奇引擎

> 配套技术方案见 [ENGINE_REBOOT.md](ENGINE_REBOOT.md)。
> 节奏原则：每个里程碑结束时**可运行、可演示、可验收**；UI 设计稿作为并行轨道先行。

## 里程碑总览

| 阶段 | 主题 | 核心交付 |
|---|---|---|
| M0 | 仓库与资源解码 | 新仓库脚手架 + mir-formats crate 全格式解码 |
| M1 | 客户端最小可玩 | 直读原版地图+精灵，单机漫游，高分缩放成立 |
| M2 | 联机基础 | 共享 protocol/sim，登录/选角/移动同步/断线恢复 |
| M3 | 玩法迁移 | 战斗/技能/掉落/背包装备/怪物 AI + 过渡版 HUD |
| M4 | UI 现代化全量 | 设计稿评审通过 → 全界面 Bevy UI 落地 + 高分打磨 |
| M5 | 开源发布 | 许可/CI/文档/资源指引，对外可用 |
| M6+ | 增强项 | 编辑器、超分缓存、WASM 网页版、Mir3 格式… |

并行轨道：**UI 设计稿在 M1 期间启动**（现代 MMO 风格全套视觉：登录/选角/HUD/背包/角色/技能/聊天/小地图），
M3 结束前完成评审定稿，M4 只做实现不做方向讨论。

## M0 仓库与资源解码

**目标**：新仓库就位；三类原版资源在 Rust 侧解码全部过测试。

| # | 任务 | 说明 / 验收 |
|---|---|---|
| 0.1 | 仓库脚手架 | cargo workspace（crates/×4 + server + client + tools）；MIT/Apache 双许可；rustfmt/clippy/CI（fmt+clippy+test）；README 骨架 |
| 0.2 | mir-formats: .map | type0/1/100 解析 + 阻挡位（旧 JS 实现为蓝本）；合成样本往返测试 |
| 0.3 | mir-formats: Crystal .Lib | v2/v3、GZip ARGB、偏移元数据；金样本测试 |
| 0.4 | mir-formats: WIL/WIX | 8bpp 调色板/16bpp 变体；真实样本回归（本地验证，样本不入库） |
| 0.5 | mir-formats: WZL/WZX | zlib 帧；同上 |
| 0.6 | 资源目录扫描器 | 给定目录 → 归一化索引（地图列表/图库清单/帧数）；对不认识的文件降级警告不崩溃 |
| 0.7 | CI 合规检查 | 阻止二进制资源入库（后缀+体积白名单） |

**验收**：`cargo test` 全绿；指向真实资源目录运行索引器，输出完整清单且零崩溃。

## M1 客户端最小可玩（单机）

**目标**：Bevy 客户端直读原版资源渲染世界，键鼠漫游，高分策略成立。

| # | 任务 | 说明 / 验收 |
|---|---|---|
| 1.1 | Bevy 工程 + 窗口/相机 | 锁定 Bevy 版本；窗口任意缩放、scale_factor 正确 |
| 1.2 | mir-atlas 运行时图集 | 按需解码入 4096² 图集页 + LRU；磁盘缓存（内容哈希键），二启秒开 |
| 1.3 | 地图渲染 | back(96×64 偶数格)/mid/front 分层；front 底对齐+偏移+行深度；视口窗口化加载 |
| 1.4 | 精灵渲染 | 角色 8 向站立/行走动画（任选一套资源）；锚点/朝向正确 |
| 1.5 | 本机漫游 | sim crate 初版（子格行走性来自 .map 阻挡位 + 圆形体 + 滑行）；右键移动 |
| 1.6 | 高分缩放 | 世界整数倍最近邻（1x/2x/3x 自动）；4K 全屏与 1080p 窗口双验收 |
| 1.7 | debug 面板 | bevy_egui：FPS/图集页/实体数/传送坐标 |

**验收**：原版比奇省地图内漫游流畅（60fps@4K），碰撞与视觉一致，二次启动 <2s。

## M2 联机基础

**目标**：登录→选角→进图→多人同屏移动→断线恢复，全链路走共享 crate。

| # | 任务 | 说明 / 验收 |
|---|---|---|
| 2.1 | protocol crate | 42 消息迁入 + serde + 协议版本字段；服务器/客户端同源引用 |
| 2.2 | 服务器迁入（基座） | 账号/会话/sessionToken/心跳/区域广播分组迁到新仓库；地图加载改直读 .map + JSON 边车（出生点/传送门） |
| 2.3 | sim 双端接线 | 服务器校验与客户端预测调同一函数；斜向滑行双端一致 |
| 2.4 | 客户端 net+prediction | 连接/重连/Resume；预测+权威校正（20Hz） |
| 2.5 | 过渡版登录/选角 UI | Bevy UI 素排版（不追求皮肤），流程可用 |
| 2.6 | 传送门/区域切换 | 边车驱动；双向切换回归 |

**验收**：两客户端同屏互见移动；拔线 120s 内重连原位恢复；协议仅存在于 protocol crate。

## 完成的定义（DoD，全里程碑通用）

- `cargo fmt` / `clippy -D warnings` / `cargo test` 全绿，CI 通过；
- 新逻辑有测试（格式解码必须金样本；玩法逻辑保持现有测试密度）；
- 涉及双端的行为，共享 crate 是唯一实现；
- 文档随代码更新（格式矩阵/边车字段/设置项）。
